# Типографика постов: читаемость текста

Дата: 2026-11-10
Папка: `frontend/`

## Задача

Разобрать стили контента Tiptap (`.tiptap` в `app/assets/css/editor.css`), сверить их с
общепринятыми правилами читаемости длинного текста и внести правки.

## Что было

- `.tiptap` — глобальный класс, применяется не только к постам, но и к `page/[slug].vue`,
  `document/[slug].vue`, книгам, афише, комиксам, играм, Пушкинской карте.
- Абзац: `indent-12 mb-4 leading-7` (16px, межстрочный 28px, красная строка 48px).
- Колонка поста: `<article class="max-w-4xl">` → при 16px и Montserrat ≈ **120–130
  символов в строке** при норме 60–75. Это и была главная причина утомления.
- Ссылки: `hover:opacity-70` — снижал контраст при наведении на белом фоне.
- Цитаты: без верхнего/нижнего отступа, без цвета текста, без сброса отступа абзацев.
- Списки: `ml-12 mr-6` — уже абзаца, левый край «рвался».
- Код (`pre` / `code`) — стилей не было вообще.
- `h1` в CMS-контенте конкурировал с `h1` страницы.

## Что сделано

### `app/assets/css/editor.css` — блок `.tiptap`

1. **Кегль и интервал на контейнере**: `font-size: 1.0625rem` (17px), `line-height: 1.75`,
   `text-wrap: pretty`, `-webkit-font-smoothing: antialiased`. Ставится на `.tiptap`, а не на
   `p` — чтобы масштаб наследовали списки, таблицы, цитаты, код.
2. **Перенос длинных слов**: `overflow-wrap: break-word; hyphens: auto` — в узкой колонке на
   мобильном слова и ссылки больше не распирают строку.
3. **Заголовки**: `mt-12 mb-3` для h2/h1 (заголовок ближе к своему тексту, чем к предыдущему),
   `mt-10` для h3, `mt-8` для h4, добавлен `tracking-tight`. `h1` в контенте приведён к
   размеру h2 — больше не спорит с заголовком страницы.
4. **Абзацы**: `indent-8` (32px ≈ 1.9em при 17px) — красная строка сохранена по указанию
   владельца, но уменьшена: прежние `indent-12` (48px) были заметно больше набора
   (классика — 1.25–2em). Отступ между абзацами `mb-5` (20px ≈ 1.18em). Сброс `indent-0`
   оставлен там, где красная строка не нужна: списки, цитаты, ячейки таблиц.
5. **Списки**: `ml-6 mr-0 pl-6` — левый край совпадает с абзацем.
6. **Цитаты**: `border-l-4`, `padding 0.75rem 1rem`, `margin 2rem 0`, цвет `neutral-700`,
   скругление только справа, абзацы внутри без нижнего отступа, между абзацами 1rem.
7. **Ссылки**: `underline-offset-2` (подчёркивание не липнет к тексту), `hover:opacity-70`
   заменён на `hover:text-primary-700` — контраст не падает.
8. **Картинки**: добавлен `max-height: 70vh; object-fit: contain` — очень высокие скриншоты
   не растягивают страницу на несколько экранов.
9. **Код** (новое): `pre` — фон `neutral-200`, `overflow-x-auto`, `tab-size: 2`;
   `code` — моношрифт, полупрозрачный фон; `pre code` — без дублирующего фона.

### `app/pages/post/[slug].vue`

- `<article class="max-w-4xl">` → `max-w-3xl` (768px). При 17px и паддингах контейнера это
  даёт ≈65–68 символов в строке — целевой диапазон.

## Проверки

- `npx eslint app/pages/post/[slug].vue` — без ошибок (код 0).
- Сборка CSS через `@tailwindcss/vite` + `vite` в middleware-режиме: 380 КБ, все новые
  свойства присутствуют в выводе (`font-size: 1.0625rem`, `line-height: 1.75`,
  `text-wrap: pretty`, `max-height: 70vh`, `hyphens: auto`). Значит `@apply` во вложенных
  селекторах и произвольные значения Tailwind v4 скомпилировались.
- Prettier по `post/[slug].vue` ругается, но файл был неотформатирован **до** правок
  (проверено через `git stash`), чужие строки не переформатировал.

## Что осталось / на заметку

- Кегль 17px теперь применяется на всех страницах с `.tiptap`. На странице книги
  (`books/[slug].vue`) классы `text-[1.0625rem] leading-[1.75]` стали дублем — можно убрать
  отдельной мелкой правкой.
- Таблицы данных, если появятся, требуют отдельного оформления: сейчас ячейки `6px 8px`
  рассчитаны на группировку фото.
- Визуальную проверку в браузере не делал: dev-сервер на `localhost:3000` не запущен,
  правка охватывает много страниц — если что-то поедет, откатить можно
  `git checkout -- app/assets/css/editor.css app/pages/post/[slug].vue`.
