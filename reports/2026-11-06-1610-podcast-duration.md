# Длительность подкастов: карточка и плеер

Дата: 2026-11-06 16:10

## Что сделано — backend

### Схема и миграция
`File.duration Int?` — длительность аудио в секундах.
Миграция `prisma/migrations/20261106150000_file_duration` (+`npx prisma migrate deploy`
на локальной БД). Прод не трогался.

### Расчёт при загрузке
- `src/files/utils/audio-duration.utils.ts` — `readAudioDuration(buffer)`:
  разбирает mp3/m4a/wav/ogg/flac через `music-metadata` (динамический import,
  т.к. пакет ESM-only), округляет до секунд; при ошибке возвращает `null` —
  загрузка не падает из-за нераспознанного формата.
- `FilesService.uploadAudio` сохраняет `duration` вместе с файлом; для повторно
  загруженного файла (тот же хеш) возвращается существующая запись.

### Старые файлы
`src/files/scripts/backfill-audio-duration.ts`, запуск:

```bash
npm run audio:duration-backfill
```

Перебирает `File.type = AUDIO` с `duration = null`, скачивает объект из хранилища,
пишет секунды. Один запуск — один проход; нераспознанные остаются `null`.

## Что сделано — сайт

- `services/types/file.type.ts` — `duration?: number | null`.
- `app/utils/duration.ts` — `formatDuration` («12:34», «1:02:03»),
  `eventPodcastDuration` (безопасное число из API).
- `app/composables/usePodcastPlayer.ts` — состояние `currentTime` и `duration`,
  методы `seek(seconds)` и `skip(delta)`; длительность берётся из метаданных
  `<audio>`, а пока они не загрузились — из поля `File.duration`.
- `app/components/podcast/Card.vue` — под описанием длительность с иконкой часов
  (из `podcast.audio.duration`, затем из метаданных, если трек уже играет).
- `app/components/podcast/Player.vue` — вторая строка плеера: счётчик
  «прошло / всего» (`0:14` … `13:15`), полоса перемотки с заливкой до бегунка,
  кнопки «−15 секунд» и «+15 секунд», `aria-valuetext` «0:14 из 13:15».

## Как проверено

1. Backend: `npm run build`; `readAudioDuration` на сгенерированном WAV 3 с → `3`,
   на мусорных байтах → `null`; скрипт досчёта запущен на локальной БД — до реальных
   загруженных файлов дошёл и корректно сообщил об отсутствующем в хранилище `ПОДКАСТ .MP3`.
2. Сайт: `npx eslint` по изменённым файлам — без ошибок.
3. Браузер (`temp/ui.mjs`, отдельный профиль, `--headless=new`, закрыт после прогона):
   - карточка подкаста во вкладке «Подкасты» полки на главной показывает `13:15`;
   - после «Слушать» плеер показал `0:04` / `13:15`, полоса активна;
   - «+15 секунд» → `0:21 из 13:15`;
   - перетаскивание ползунка на середину → `6:37 из 13:15`;
   - скриншоты: `temp/podcast-cards.png`, `temp/podcast-player.png`.
